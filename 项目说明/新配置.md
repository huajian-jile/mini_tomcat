完整启动部署流程
1. 首次启动（自动生成配置）

java -cp /path/to/mini_tomcat/out Main
自动生成：


当前目录/
├── apps.json           # 应用配置
├── conf/
│   └── server.xml     # 服务器配置
└── webapps/
└── ROOT/
└── index.html
2. 部署应用
   方式一：放目录


webapps/
└── myapp/             # 直接放目录
└── index.html
方式二：放 WAR 包


webapps/
└── myapp.war          # 放 WAR 包
3. 重启 Tomcat
   停止后重新启动，自动：

解压 WAR 包（如有）
扫描 webapps/ 目录
更新 apps.json
4. 访问应用
   http://localhost:9000/ → ROOT
   http://localhost:9000/myapp/ → myapp
   一句话：放应用 → 重启 → 访问
